# 🚑 SSMP Plus (СМП Плюс)

Мобильный ассистент выездной бригады скорой медицинской помощи для ускоренного и удобного заполнения карт вызовов.

---

## ⚡ Основные возможности

* **⚡ Умное автозаполнение:** автоматическая подстановка анамнеза, жалоб, привычного АД и ранее зафиксированных данных при повторном вызове к пациенту.
* **💾 Автосохранение «на лету»:** если пациент обслуживается впервые, приложение тихо запоминает его данные в локальный архив сразу при вводе.
* **🔍 Локальный архив вызовов:** поиск по базе пациентов прямо с главного экрана даже при отсутствии интернета (в подвалах, лифтах, отдаленных деревнях).
* **🎯 Умный выбор карточки:** если к пациенту было несколько выездов, алгоритм выберет наиболее полную и информативную карту для автозаполнения.
* **📱 Оптимизировано под мобильные устройства:** жесты «Назад», защита от случайного выхода, адаптивный интерфейс и скрытие кнопок вне рабочего экрана.

---

## 🔒 Безопасность и врачебная тайна

* **Offline-First хранилище:** вся база данных пациентов хранится **исключительно локально на физическом устройстве** в защищенной системной базе SQLite.
* **Никаких сторонних серверов:** персональные данные пациентов и медицинская тайна **не передаются** в облака или на сторонние сервера (полное соответствие нормам законодательства о защите персональных данных РБ).

---

## 📥 Установка и обновления

Каждый раз при обновлении кода робот GitHub Actions автоматически компилирует и подписывает приложение:

1. Перейдите во вкладку [Releases](../../releases).
2. Скачайте актуальный файл **`SSMP-Plus-v1.0.X.apk`** (без необходимости распаковывать ZIP).
3. Установите поверх предыдущей версии — постоянная цифровая подпись сохраняет все локальные данные пациентов.
