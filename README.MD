# 🚑 SSMP Plus (Android & iOS Edition)

Мобильный ассистент выездной бригады скорой медицинской помощи для ускоренного, точного и удобного заполнения электронных карт вызовов.

---

## ✨ Главные возможности

### ☰ Единое меню управления (на главном экране)
Компактная круглая кнопка **`☰`** в правом нижнем углу главного экрана открывает центральное меню с 5 разделами:

1. **⭐ Образцы карт СМП (25 встроенных шаблонов):**
   * Встроенная база эталонных клинических описаний по самым частым вызовам скорой помощи: *Гипертонический криз, Пароксизм ФП, ОКС (с подъемом и без подъема ST), Отек легких, ОНМК (Инсульт), ТИА, Обморок/Синкопе, Бронхиальная астма, ХОБЛ, Пневмония, ОРВИ/Гипертермия, Эпилепсия, Гипогликемия, Острый аппендицит, Панкреатит, Холецистит, ЖКК, Почечная колика, ЗЧМТ/СГМ, Перелом шейки бедра, Отек Квинке, Анафилактический шок, Люмбалгия, Констатация биологической смерти*.
   * Поиск по названию патологии или коду МКБ и вставка шаблона в открытую карту в один клик (**«⚡ Вставить»**).
2. **📂 Общий архив вызовов:**
   * Персональная картотека пациентов, которых вы сохранили кнопкой **`💾`**.
   * Прямое считывание структуры карты из API (жалобы, анамнез, перенесенные заболевания, витальные показатели, ЭКГ, введенные препараты с дозировками и путями введения).
   * Хронология выездов к пациенту по датам, цветные медицинские бейджи (**❤️ АД**, **💓 ЧСС**, **🫁 SpO2**, **🩸 Гликемия**, **🧠 Глазго**) и возможность удаления ненужных записей.
3. **📖 Полный справочник МКБ-10 (12 500+ диагнозов):**
   * Полный официальный реестр диагнозов, работающий полностью оффлайн.
   * Быстрые фильтры по экстренным профилям СМП (**❤️ Кардио**, **🫁 Дыхание**, **🧠 Невро**, **🩹 Травмы**, **🧪 Токсико**, **🚨 Симптомы**, **🤢 ЖКТ**, **🩸 Эндокрин**, **🤰 Акушерство**, **👂 ЛОР** и др.).
   * Копирование кода и названия диагноза в буфер обмена одним нажатием.
4. **📥 Импорт базы и 📤 Экспорт базы:**
   * Сохранение всего накопленного архива пациентов в файл `ssmp_archive.json` в память телефона и быстрое восстановление базы при смене устройства.

### ⚡ Интеллектуальный автопилот внутри карты (`💾` и `⚡`)
* **Плавное заполнение Material-UI без дергания экрана:** заполняет текстовые поля, нажимает кнопки-переключатели и выбирает пункты в выпадающих списках (`Общее состояние`, `Сознание`, `Тоны сердца`, `Дыхание`, `Перкуссия`, `Живот`, `Кожа`).
* **Автоматическое дозаполнение вкладок:** выбранный шаблон или карта пациента запоминается для текущего вызова — при переходе на вкладки *«Объективные данные»* и *«Медицинская помощь»* (включая блоки **во время и после транспортировки**) поля заполняются автоматически.
* **Умная дата рождения и возраст:** автоматически проставляет время рождения **`00:00`** (за исключением новорожденных в день вызова) и рассчитывает возраст пациента.
* **Поддержка констатаций:** корректная обработка нулевых показателей гемодинамики (`0/0`).

---

## 🔒 Безопасность и конфиденциальность

* **Offline-First архитектура:** вся база данных пациентов хранится **исключительно локально в памяти вашего устройства** (`SQLite` на Android / `localStorage` на iOS).
* **Никаких сторонних облаков:** данные пациентов не отправляются на внешние серверы. Импорт и экспорт резервных копий выполняются локально через файловую систему телефона.

## 📥 Установка и обновление

Робот GitHub Actions автоматически собирает свежую версию при каждом обновлении кода. Все готовые файлы находятся в разделе **[Releases](../../releases)**:

### 📱 Для Android:
1. Перейдите во вкладку **[Releases](../../releases)**.
2. Скачайте файл **`SSMP-Plus-v1.0.X.apk`** и установите его на смартфон.
3. Приложение подписано постоянным ключом — все обновления устанавливаются поверх старой версии с полным сохранением вашей базы данных.

### 🍏 Для iOS (iPhone / iPad — через Safari):
1. Установите из App Store бесплатное расширение для пользовательских скриптов Safari: **[Stay](https://apps.apple.com/app/stay-for-safari/id1591620171)** или **[Userscripts](https://apps.apple.com/app/userscripts/id1463298887)**.
2. Включите расширение в настройках iPhone: *Настройки ➔ Safari ➔ Расширения ➔ Stay / Userscripts (Разрешить)*.
3. Скачайте из раздела **[Releases](../../releases)** файл **`SSMP-Plus-iOS.user.js`** и добавьте его в расширение.
4. Откройте рабочий сайт в Safari — кнопки меню и автопилота появятся автоматически!
